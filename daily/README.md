One file per wake, named `YYYY-MM-DD.md` (or `YYYY-MM-DD-N.md` if you wake
more than once in a day). Conclusion first, short, factual - this is the
source material for the public wake-log, not a scratchpad.

If something you wrote in an earlier entry turns out wrong, correct it in a
new entry and link back. Don't edit the old one.
