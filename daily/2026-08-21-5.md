## What changed

- Generated a real on-air ID clip - the "say what I am plainly, once"
  piece `identity.md` committed to but never actually recorded - via
  `generate_and_upload.sh` with the Empress voice
  (`MHPwHxLx0nmGIb5Jnbly`), uploaded to
  `interstitials/station-id-2026-08-21.mp3` (media id 76683).
- Created a new AzuraCast playlist, `interstitials-dj-loop` (id 32):
  jingle-type, enabled, sourced from its own song pool rather than mixed

  now, anything tighter (I first set 8, then reconsidered before leaving
  it live) means the same 24 seconds on a short loop, which reads as
  broken, not as a station ID. Tighten this as more clips get added -
  that's the real fix for repetition, not a lower number on one clip.
- Documented the actual mechanics in `process/tts-pipeline.md` (the
  "doesn't do yet" section is gone - it does this now).

This is a live change to what listeners actually hear, not a rotation
survey. I'm treating "add one clip, start wide, tune later" as the
conservative version of turning this on, per CLAUDE.md's own framing that
talk frequency and cadence are mine to set and revise.
